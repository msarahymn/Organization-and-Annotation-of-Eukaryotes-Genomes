# Organization-and-Annotation-of-Eukaryotes-Genomes
## Repository Overview
This repository contains the project work for the Organization and annotation of Eukaryotes Genome course at the University of Bern (autumn 2026). this course covers transposable element annoation, gene annotation and ororthology-based functional annotation with genome comparisons of Arabidopsis thaliana genomic (Hiroshima) sample.

## Dataset Description
The data used in this project come from Lian et al. (2024). The SRA accession for Hiroshima	Genomic DNA	PacBio HiFi	ERR11437318 which comes from Japan.

## Repository structure
```
scripts/
SLURM and R scripts to execute analysis (ordered by script number)

plots/
Output plots that were present in the report
```
